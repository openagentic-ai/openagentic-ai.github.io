01 / FIRST USE CASE

先把一件小事，
完整地做好。

第一个验证场景：个人笔记 → 待办简报。
不需要先搭工作流，从一个授权文件夹开始。

PERSONAL WORKSPACE 交互示意

一个文件夹，就是起点。

不用把所有资料都交出去。只读取你指定的笔记，不修改原文件。

▤ 本周安排.md 时间与计划
▤ 演示记录.md 进度与疑问
▤ 个人备忘.md 日常待办

此处展示交互流程，不会读取你的设备，也不会调用模型。

02 / YOUR MODEL. YOUR CHOICE.

本地优先。
选择权始终在你。

同一个助手，两种模型接入方式。
让数据边界成为明确的选择。

⌘ 本地模型

在自己的机器上思考。

连接本机推理服务，用本地模型处理笔记。此演示的本地模式在调用失败时直接报错，不会自动转云端。

你的笔记 → 本机模型 → 本地简报
效果与速度取决于模型和硬件；普通电脑适配仍待验证。
↗ 自带 API key

也能用你选择的云端模型。

保留 API 接入能力。演示支持 OpenAI 兼容端点，明确显示模型模式，生成前提醒资料将发送至所选服务。

授权资料 → 所选 API → 本地简报
API 模式涉及资料外发，费用及数据处理规则由供应商决定。
